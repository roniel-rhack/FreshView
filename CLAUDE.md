# Project guidance

Read [AGENTS.md](AGENTS.md) for FreshView's architecture, working agreements, and verification requirements. [README.md](README.md) documents installation, current store availability, development commands, and product limitations.

FreshView is a maintained fork of the original project. It uses vanilla JavaScript and Manifest V3, with a Chromium service worker and Firefox background scripts. The root directory is the unpacked extension; no build system or runtime dependencies are required.

Keep this file as a pointer to the shared guidance rather than duplicating architecture or compatibility claims that can drift.
